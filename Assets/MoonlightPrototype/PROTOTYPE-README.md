# 문라이트 로열 첫 시제품

이 시제품은 기본 도형과 임시 UI를 사용합니다. 실제 게임 에셋과 성인 콘텐츠는 포함하지 않습니다.

---
## Unity에서 열기

1. Unity Hub에서 `D:\Project-Upsilon`을 기존 프로젝트로 추가하고 Unity 6000.3.21f1로 엽니다.
2. 패키지 가져오기와 스크립트 컴파일이 끝난 후 `Assets/Moonlight/Prototype.unity`를 엽니다. 장면이 없을 때만 `Moonlight > 시제품 장면 만들기`를 선택합니다. 생성 명령은 현재 장면을 교체하므로 현재 장면의 변경 사항은 먼저 저장합니다.
3. 생성된 `Moonlight Prototype` 오브젝트를 선택하면 Inspector의 Settings에서 시간, 청구 주기, 업무 보수, 시작 칩, 베팅 한도와 딜러 규칙을 변경할 수 있습니다. Play를 눌러 실행합니다.
4. WASD와 마우스로 이동하고 E로 가까운 루나, 업무 장소, 블랙잭 테이블, 정산 창구를 이용합니다. 가까이 가면 상호작용 안내가 표시됩니다. Esc는 일시정지, F5는 수동 저장, F9는 수동 불러오기입니다.

입구·중앙 홀·블랙잭·룰렛·슬롯·무대·라운지는 기본 도형으로 구성한 임시 공간입니다. 룰렛과 슬롯은 아직 장식입니다.

---
## 임시 수치와 규칙

- 시작 칩 5,000,000, 업무 보수 4,000,000, 업무 시간 게임 내 120분, 베팅 범위 1,000,000~20,000,000칩.
- 현실 1초당 게임 내 2분, 청구 주기 게임 내 72시간. 기본 빚과 청구율은 인계 수치를 사용합니다.
- 블랙잭은 매 판 1덱을 새로 섞고, 딜러는 소프트 17에 스탠드합니다. 내추럴 블랙잭은 이익 3:2, 일반 승리는 이익 1:1, 무승부는 원금 반환입니다. 더블, 스플릿, 보험은 없습니다.
- 최대 36회 업무의 이론상 수입은 시작 칩 포함 149,000,000칩입니다. 첫 청구액 122,400,000칩보다 많지만 이동과 조작에 걸리는 시간 및 실제 난이도 조정은 검증이 필요합니다.
- 저장 위치는 Unity `Application.persistentDataPath`이며 수동, 시작, 이벤트, 청구 직전, 정산 직후 슬롯을 구분합니다.

---
## 검증과 남은 작업

독립 규칙 검증은 프로젝트 루트에서 `dotnet build MoonlightVerification/Verification.csproj` 후 `dotnet MoonlightVerification/bin/Debug/net10.0/Verification.dll`로 실행합니다. Unity 저장은 JsonUtility를 사용하므로 별도의 Unity 실행 검증이 필요합니다.

Unity 물리 충돌 기반의 자동 경로 탐색으로 입구에서 네 상호작용 범위에 도달할 수 있는지 검사합니다. 실제 플레이를 통한 화면 크기와 한글 폰트, 조작감, UI 열기·닫기, 저장 복구와 청구 시각 경계의 통합 검증이 필요합니다. 실제 에셋 교체, 오디오, 정식 UI, 나머지 카지노 게임과 콘텐츠는 추후 작업입니다.
